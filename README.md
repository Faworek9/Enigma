# 🔐 Enigma Desktop App

Nowoczesna aplikacja desktopowa w Pythonie odwzorowująca logikę szyfrowania maszyny **Enigma**, wyposażona w graficzny interfejs użytkownika (GUI).

![Enigma Screenshot](ikona.ico) <!-- Tutaj możesz podmienić ścieżkę na screen aplikacji -->

## 🚀 Funkcje
* **Szyfrowanie w czasie rzeczywistym** – wykorzystuje mechanizm pierścieni i przesunięć znanych z maszyny Enigma.
* **Nowoczesne GUI** – wybudowane w oparciu o CustomTkinter (Dark Mode).
* **Standalone .exe** – uruchamia się na systemie Windows bez konieczności instalacji Pythona.

## 🛠️ Technologie
* **Python 3.x**
* **CustomTkinter** – interfejs graficzny
* **PyInstaller** – kompilacja do pliku `.exe`
